# Features Overview

OpenStudio Hub is built around solving daily frustrations for artists and studios by eliminating technical friction. This section explores the core tools designed to automate your pipeline, protect your intellectual property, and remove human error from the equation.

Explore our key features:

* **[Automated QA & Auto-Fixing](features/automated-qa.md):** Learn how the Gatekeeper engine detects and automatically fixes missing textures, dirty geometry, and incorrect naming conventions before an artist can publish their work.
* **[Vendor Jailing & Sparse Checkout](features/vendor-jailing.md):** Discover how the system isolates projects so external freelancers (vendors) only download the specific files they need, saving bandwidth and protecting your IP.
* **[Automated Task Orchestration](features/kitsu-orchestration.md):** See how direct Kitsu integration translates database tasks into physical folder paths and creates master `.blend` files automatically.
* **[Standardized Workspaces & Sandboxing](features/standardized-workspaces.md):** Understand how the Hub ensures the entire team uses the exact same Blender version and tools by running them in an isolated environment.
