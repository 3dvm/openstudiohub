# Artist Survival Guide

Welcome to your new workspace! The OpenStudio Hub was designed with one simple philosophy: **Artists should only focus on art.** 

You no longer need to worry about naming conventions, folder structures, or configuring add-ons. The Hub handles all the technical heavy lifting, Version Control System (VCS) commands, and server connections automatically.

Follow this guide to master your daily workflow:

* **[Getting Started](artist-guide/getting-started.md):** Learn how to log in, understand your dashboard, and see how the Hub securely manages your credentials in RAM (Zero-Disk Passwords).
* **[The Daily Workflow](artist-guide/daily-workflow.md):** A simple, step-by-step guide on how to use the "Work" and "Publish" buttons to launch your pre-configured Blender environment and submit your tasks for review.
* **[Managing Feedback & Notes](artist-guide/feedback-and-notes.md):** Learn how to read supervisor correction notes and mark them as acknowledged directly inside the Hub's Activity Feed, without ever opening your web browser.
