# Getting Started

Welcome to OpenStudioHub! This guide will help you set up your workspace and understand your new dashboard. Our goal is to let you focus entirely on your art, while the Hub handles the folders, files, and server connections behind the scenes.

## 1. Logging In
Launch the OpenStudioHub application. You will be greeted by the login screen.

* Enter your studio credentials (the same ones you use for Kitsu).
* **Security Note:** The Hub uses a "Zero-Disk Password" policy. This means your version control (SVN) credentials are never saved to your hard drive. You may occasionally see a Just-In-Time (JIT) pop-up asking for your SVN password before downloading files; this is kept securely in your computer's RAM only while the app is open. It also means that you can't save your login information, you need to insert your password everytime you start working.

## 2. The Artist Dashboard
Once logged in, you will see your main dashboard (`ViewArtist`).

* **Your Projects:** The dashboard opens on **My Projects**, showing only the productions where you have assigned tasks. Each card displays the project thumbnail and how many tasks you own there.
* **Your Tasks:** Click a project card (or its **Open Tasks** button) to jump to **My Tasks** scoped to that project. The task cards show status, thumbnail, a VCS lock badge when relevant, and a comment badge.
* **Comments:** The comment badge (`💬 N`) shows the total number of comments and turns orange when there are new ones. Click it to open the right-side comments drawer, read the thread, reply and tick checklist items. A second `☑ x/y` badge shows the checklist progress. See [Managing Feedback & Notes](feedback-and-notes.md).
* **Dynamic Syncing:** If your supervisor assigns you a new task or writes a comment while the Hub is open, click the "↻ Refresh" button to fetch the latest assignments and comment badges.

## 3. Your Workspace
You don't need to configure Blender, install add-ons, or map network drives. The Hub downloads the studio-approved Blender version and sets up a standard, isolated workspace for you automatically.
